# 🎓 CampusConnect

CampusConnect is a centralized platform built for our college community to simplify everyday campus life. It brings together essential services like Lost & Found, Announcements, Events, College News, Hostel & PG Finder, Bus Schedules, and Scholarship information into one easy-to-use web application.

Our goal is to make campus information more accessible, organized, and connected for students and faculty.

> 🚧 This project is currently under development.
